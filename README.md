# 生意参谋自动下载

一个用于辅助下载生意参谋数据的 Chrome 扩展，配合 Windows 本地辅助程序选择目录、检查已有文件并归档下载结果。当前扩展版本为 **0.8.24**。

## 功能

- 按固定日期规则处理商品排行、店铺来源、搜索词分析和内容数据；只执行已设置目录的项目。
- 下载前根据类别和完整日期范围检查目标月份目录，跳过匹配的已有文件。
- 将浏览器下载的文件归档到所选目录；遇到内容不同的同名文件时停止并保留双方文件。
- 在扩展的“目录与状态”页面查看流程状态和下载记录。

## 安装和使用

需要 64 位 Windows、Chrome 和已登录的生意参谋账号。安装包已包含本地辅助程序，无需单独安装 Python。

1. 下载并完整解压本仓库，在 `sycm-auto-download/native` 下双击 `install.cmd`，为当前 Windows 用户安装本地辅助程序。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，选中 `sycm-auto-download` 文件夹。安装后不要移动或删除该文件夹。
3. 登录生意参谋，在扩展菜单打开“目录与状态”，为需要下载的类别选择保存根目录，然后点击“开始下载”。网络目录需要当前 Windows 用户具有读写权限。

不同电脑或 Windows 用户需要分别安装辅助程序。更新辅助程序后重新运行 `install.cmd`，更新扩展后在 Chrome 扩展页面刷新扩展。不同店铺请使用不同的根目录。

详细日期规则、归档行为和故障处理见 [使用说明](使用说明.md) 和 [扩展说明](sycm-auto-download/README.md)，图文步骤见 [使用说明书](生意参谋自动下载插件使用说明书.docx)。

搜索词分析在周一和周四下载截至前一天的 7 天数据；日期规则以 Markdown 说明为准，图文说明书可能未包含最新调整。

## 注意事项

- 当前需要手动启动，没有每日自动定时启动功能；固定日期规则不会自动查找更早遗漏的数据。
- 真实平台流程尚未完成端到端验证。首次使用时请检查页面日期、流程状态和归档文件；平台页面或下载行为变化可能导致流程失败。
- 文件先进入 Chrome 默认下载目录，归档验证成功后才删除原文件。出现冲突或失败时，请检查状态并保留下载目录中的文件。

## 项目结构与验证

- `sycm-auto-download/`：扩展源码、页面和 JavaScript 测试。
- `sycm-auto-download/native/`：Windows 辅助程序、源码、安装脚本及 Python 测试。
- `使用说明.md`、说明书和图片：安装及使用资料。

在 `sycm-auto-download` 目录下可运行 `node --test *.test.js` 和 `python -m unittest discover -s native -p 'test_*.py'`。Python 测试需要安装 `native/requirements.txt` 中的依赖。
