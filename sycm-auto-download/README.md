# 生意参谋商品、店铺来源与内容下载扩展

本扩展需要 Chrome、已登录的生意参谋账号和配套的 Windows 本地辅助程序。安装或更新扩展后，在扩展菜单选择“目录与状态”，只需设置需要下载的项目的根目录；未设置的项目会跳过。点击目录旁的“清除”可取消该项目，流程运行中需先停止流程才能修改目录。

点击扩展菜单“开始下载”后，扩展按商品排行、店铺来源、搜索词分析、内容的顺序执行已选择且当天有任务的项目。周二至周四逐日检查本周一到昨天的商品和店铺来源；周五至周日及周一检查最近一个周四到昨天的数据，已存在的文件会跳过。搜索词分析在周一和周四各下载截至昨天的7天数据；内容在周一下载上周四至周日的数据，在周四下载本周一至周三的数据。若所选项目当天没有任务，启动时会提示。日期或控件无法确认时流程停止。内容下载验证使用前天作为结束日期。状态可在目录设置页查看。当前没有每天自动定时启动功能。

文件先下载到 Chrome 默认下载目录，再复制到所选根目录下按结束日期所属月份命名的文件夹；校验成功后删除默认目录的原文件。若目标已存在同名文件，字节完全相同时去重；对 .xls 文件，还会忽略文件属性及工作簿的最后保存者记录，只有其余工作簿及内容记录完全一致才去重。确认重复后删除下载目录里的重复文件；若内容不同，停止归档并提示冲突，保留已有文件和浏览器下载目录中的新文件，不新增编号文件或覆盖原文件。所有下载类别共用此规则。跨月内容按结束日期的月份归档。服务器目录不可访问时会报错。

本机目录选择和归档依赖 Windows 本地辅助程序。使用用户安装包时，双击 `native/install.cmd` 即可为当前 Windows 用户注册，不需要填写扩展 ID 或单独安装 Python。不同电脑及不同 Windows 用户需分别安装；文件服务器需要当前 Windows 用户有读取和写入权限。源码包中的辅助程序需要先安装 `native/requirements.txt` 中的依赖，再使用 PyInstaller 构建 `sycm-native-host.exe`，具体见源码包说明。

开始下载时，本地辅助程序按文件名中的类别和完整日期范围检查对应月份目录，存在非空匹配文件则跳过并记入下载记录。请为不同店铺使用不同的根目录；文件名被更改、文件位于其他目录，或日期范围不同，均无法识别为已下载。更新本功能后需重新运行 `native/install.cmd` 安装新版辅助程序。

商品排行先选择“全部商品”和“日”，确认统计日期刷新为目标日期后，再等待下载入口出现并点击。下载入口优先按 `a.sycm-cc-item-rank-download` 识别，未找到时再找唯一可见的“下载”按钮。更新扩展后应在 `chrome://extensions` 点击该扩展的刷新按钮；目录设置页会显示当前运行版本。

页面的登录状态、元素结构、日期控件和平台下载行为可能变化。真实平台流程尚未完成端到端验证，首次使用请检查页面日期、归档状态和目标文件。若流程失败，请查看目录设置页状态，并保留默认下载目录中的文件。

当提示已有流程正在运行时，可在“目录与状态”查看进度；确需重新开始时，在扩展菜单点击“停止当前流程”，再点击“开始下载”。未归档文件保留在浏览器下载目录。

“目录与状态”显示当前或最近一次流程的下载与归档记录，包括类别、日期、结果和保存位置。成功启动新流程时清除上一轮记录；同一流程内的记录会保留到下一次启动。卸载扩展会清除记录。
